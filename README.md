# Tuner GTK4

<a href='https://flathub.org/apps/io.github.tuner_labs.tuner'>
  <img width='240' alt='Get it on Flathub' src='https://flathub.org/api/badge?locale=en'/>
</a>

An experimental GTK4 front end for the Tuner radio player. It renders the state of the Tuner core
([tuner-core](../tuner-core)) and sends it commands; it contains no radio logic of its own.

It is a prototype: it shows how far the core's API goes for a second presentation layer, and finds the gaps. See
[doc/PROTOTYPE_NOTES.md](doc/PROTOTYPE_NOTES.md) for how to build and run it, what it does, and what is missing.
