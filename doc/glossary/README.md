# Weblate glossary: additions

The glossary lives in Weblate (Tuner project, Glossary component, TBX files). It already has 51 source terms. These
files hold only the terms that are not in it yet; they are not a copy of the glossary.

`tuner-glossary-additions-en.tbx` (same terms as `tuner-glossary-additions-en.csv`): Stream, Directory, Star, Hearted,
Heart, All Time, Stream info, Metadata, Share stream URI. The explanation of each is in its `<note>`.

Import: Glossary component, English, Files, Upload. Try the `.tbx` first, the `.csv` if it is rejected. Translators
then add their language's wording.

Existing entries that probably want the `read-only` flag (not translated): Tuner, UUID, MusicBrainz, technosf,
Louis Brauer, radio-browser.info.
